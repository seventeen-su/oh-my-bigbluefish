# OMB v4.16.0 — 侧边栏控件与弹性排版规范化

> 用户要求：参考 `dsh-desktop-notify` 与相关技能，把侧边栏 UI/UX 规范为**标准控件 + 弹性排版**；
> 并排查"详情读取失败：HTTP 400：missing id"是前端误显示还是真 bug。

## 1. 400 missing id 的根因：**前端 bug**

- 现象：打开"记忆库/候选确认"页、**还没选条目**时，详情面板显示
  `详情读取失败：HTTP 400：missing id`。
- 根因：详情组件挂载时 `selectedId = null`，它的 effect 立即请求
  `/omb/api/detail`；`api()` 会跳过 null 参数，于是请求变成 `/detail`（没有 `id`），
  宿主按契约返回 `400 { error: 'missing id' }`，前端把这条**本该不存在的请求**
  的失败当成了错误状态显示出来。
- 修复：详情 effect **先判空再请求**（`id` 为空 → 清空状态、显示"从左侧选择一条记忆"），
  不再产生无 id 请求；不修改宿主的 400 语义（缺参数就该拒绝）。
- 回归：`tests/dsh/ui-bundle.test.ts` 钉住判空分支与空态文案；
  `tests/dsh/ui-route.test.ts` 继续钉住"缺 id → 400"（服务端行为没错）。

## 2. 标准控件与主题 token

浏览器 bundle 现在复用 DSH 共享控件（`PLATFORM_MODULES` 基线里的
`@deepseek-ai/dsh-client-ui-primitives`，无需 `dsh.client.external`）：

| 场景 | 控件 |
| --- | --- |
| 五个视图切换 | `SegmentedTabs`（等宽、左右/Home/End 键盘、滑动指示器） |
| 作用域 / 状态过滤 | `SegmentedControl`（受控、tablist 语义、禁用态） |
| 类型过滤 | `Pill`（可选中胶囊） |
| 搜索框 | `Input`（原生输入、可清空、焦点可见） |
| 动作按钮 | `Button`（primary/outline/ghost、sm 28px） |
| 阶段/类型/审计标签 | `Tag`（8 种 tone，按状态选色） |
| 库就绪/隐私闸门 | `StateDot`（done/warning/error + 文本，不单靠颜色） |

样式走 `--dsw-*` 语义 token（`--dsw-alias-label-*`、`--dsw-alias-border-l2`、
`--dsw-radius-md/lg`、`--dsw-alias-interactive-bg-hover`、`--dsw-focus-ring-color`），
**不写死色值**；`tests/dsh/ui-bundle.test.ts` 断言无十六进制颜色、控件与 token 都在用。
`tests/dsh/no-host-imports.test.ts` 把"浏览器 bundle 共享模块请求"作为**文件 + 说明符**
的精确例外，并断言该例外仍被使用（过期例外同样失败）。

## 3. 弹性排版

- 页面：`height:100%; min-height:0; display:flex; flex-direction:column`，内容区
  `flex:1; min-height:0`，列表/详情各自滚动，不产生整页横向滚动；
- 概览/运行状态卡片：`grid-template-columns: repeat(auto-fit, minmax(180px, 1fr))`；
- 记忆库工作区：窄容器单列，`@media (min-width:900px)` 起两列
  `minmax(0,5fr) / minmax(0,7fr)`；所有网格轨道带 `minmax(0, …)`，长文本 `overflow-wrap:anywhere`；
- 圆角/边框/焦点环走主题；不写死 `width/height` 的控件尺寸，交给控件自身（Button sm / Input）。

## 4. 本轮同时修掉的问题

1. **候选分页语义**：旧实现先 `list(limit)` 再过滤候选，库里有大量已确认/事件条目时
   排在后面的候选会被漏掉；改为先按候选判据扫描过滤、排序后再截断。
2. **概览计数诚实性**：活跃/候选计数只覆盖每个库最近 500 行；现在 `scanLimited`
   显式标记，页面写"部分库只统计最近 500 行（非全量）"，不再把上限内数字冒充全量。
3. **搜索每键请求**：旧实现 `query` 是加载回调依赖，输入每个字符都发一次请求；
   现在输入只更新本地值，停顿 250ms 或按 Enter 才请求。
4. **宿主护栏过期例外**：浏览器共享模块请求按"文件 + 说明符"豁免，并加测试防止
   例外清单腐化。

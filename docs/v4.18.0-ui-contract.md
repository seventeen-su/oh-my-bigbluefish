# OMB v4.18.0 — OMB 设置重做（契约，2026-10-24）

> 用户十项要求：手动增删改标记、合并重叠页、项目页（会话×工作区×推理深度/隐私/画像、
> 归档灰色不可读）、个人画像页、多级卡片、锁定控件样式、间距字号微调、弹性对齐、
> 动效与平滑刷新、面向用户的短文本（并追加：可选/不可选文本）。

## 1. 信息架构（4 页，二级侧边栏）

| 页 | 内容 | 替代 |
| --- | --- | --- |
| 概览 | 记忆库状态、计数、各库；运行读数（版本/闸门/控制器/捕获/活动）折叠在“运行状态”区 | 概览 + 运行状态 |
| 记忆 | 检索/过滤（含“待确认”状态）、列表、详情；新建/编辑/删除/标记；候选确认在详情内 | 记忆库 + 候选确认 |
| 项目 | 只列 `agentPreset === 'omb'` 的会话：标题、工作区、推理深度、隐私档位、归档状态；选中会话看工作区画像、设隐私、查看深度；底部“隐私维护”（基线与危险操作） | 会话隐私 + 项目画像 |
| 个人画像 | 用户级稳定偏好/意图/协作方式条目、冲突、状态 | 新增 |

- 已归档会话：灰色、不可选中/展开、不取画像、不显示隐私编辑；列表里保留（用户能看见归档状态），置灰并标注“已归档”。
- 记忆列表分页（v4.18.1）：`UiListQuery.limit`（单页 50）+ `offset`；`GET /list?limit=&offset=`
  返回 `truncated`，前端“上一页/下一页”与“第 N 页 · 本页 M 条”；过滤/搜索变化回到第 1 页。
- 页头只保留标题与一句短语；运行/技术细节折叠或放进工具提示；用户文案见 §6。

## 2. 后端契约（`modules/memory/ui.ts` + `dsh/ui-route.ts`）

### 2.1 类型

```ts
export type UiStatus = 'active' | 'stale' | 'superseded' | 'candidate' | 'all'

export interface UiMemoryCreateInput {
  readonly scope: MemoryScope            // 'user' | 'project'

  readonly text: string
  readonly tags?: readonly string[]

export interface UiMemoryUpdateInput {

  readonly tags?: readonly string[]

export interface UiSessionItem {
  readonly id: string
  readonly title: string | null
  readonly cwd: string
  readonly root: string | null
  readonly preset: string | null
  readonly archived: boolean
  readonly active: boolean
  readonly depth: string | null            // kernel.focus(sessionId)
  readonly privacy: {
    readonly mode: 'normal' | 'read-only' | 'sealed'

  } | null

  readonly available: boolean

export interface UiPersonalEntry {

    readonly available: boolean
```

### 2.2 `UiService` 新方法

```ts
createMemory(input: UiMemoryCreateInput): Promise<UiActionResult>
updateMemory(input: UiMemoryUpdateInput): Promise<UiActionResult>
deleteMemory(id: string): Promise<UiActionResult>
markMemory(id: string, mark: UiMemoryMark): Promise<UiActionResult>
sessions(): Promise<UiSessionList>
personal(): Promise<UiPersonalView>
profile(sessionId?: string): Promise<UiProfile>   // 现有方法加可选参数
```

- `list` 支持 `status:'candidate'`：active + `assertedBy==='model'` + kind semantic/procedural。
- 新建：`assertedBy='user'`、`sourceRef='ui:manual'`、`contentHash=contentHashOf(text)`、
  `id=newMemoryId(clock, hash)`、`observedAt/lastUsedAt=now`、`validTo/supersededBy=null`、
  `useCount=0`、`project=当前会话 projectScope ?? null`；project 作用域必须有当前会话，
  否则拒绝；文本 trim 后 1..4000，标签 ≤8 个、每个 ≤24 字符。
- 编辑：保留 id/observedAt/sourceRef/assertedBy/useCount；文本变了重算 contentHash；
  写后查回验证；只允许 active 记录。
- 删除：调用具体 store 的 `forget([id])`（结构化探测，缺失则如实拒绝）；删后查回不存在。
- 标记：`confirm` 复用 `deps.confirm`（与 `/omb-confirm` 同一实现）；`obsolete` 写
  `validTo=now`；`revive` 只允许 `supersededBy===null` 且写回 `validTo=null`。
- 隐私：有当前会话时经 `stores.forSession(session)` 取受闸门保护的库；无会话时用快照
  库（归属未知，禁写不禁读）；任何拒绝原样返回文本。
- `sessions()`：读 `SERVICES.sessionCatalog`；只返回 `preset==='omb'`；`root` 经
  `SERVICES.projectRoot.resolve(cwd)`；`active` 用 `SERVICES.sessionRuntime.list()`
  （存在且 observations>0）；`depth` 用 `kernel.focus(id)`；`privacy` 用
  `PrivacyAdminPort.modeOf(id)`（新增读方法）；目录不可用 → `available:false`。
- `profile(sessionId)`：按会话取 cwd（catalog 或 ActiveSessionTable）后读
  `SERVICES.projectProfile.read(cwd)`；会话已归档 → `available:false, reason:'已归档会话不可读'`；
  找不到 cwd → 如实说明。
- `personal()`：读 `SERVICES.profile`：`status()`、`entries(sessionId)`（过滤
  `provenance` 原样返回）、`conflicts(sessionId)`、`renderDeclared(12, sessionId)`；
  服务缺失 → `available:false` 与原因。

### 2.4 路由

- `GET /omb/api/sessions` → `ui.sessions()`
- `GET /omb/api/personal` → `ui.personal()`
- `GET /omb/api/profile?sessionId=...` → `ui.profile(sessionId?)`
- `POST /omb/api/memory`，JSON：
  - `{action:'create', scope, kind, text, tags?}`
  - `{action:'update', id, text?, kind?, tags?}`
  - `{action:'delete', id}`
  - `{action:'mark', id, mark:'confirm'|'obsolete'|'revive'}`
  - 参数非法 400，业务拒绝 409，成功 200 `{ok,text}`；同源/no-store/415/4KB 不变。
- `POST /privacy` 保持 set/clear/clear-inactive/trust。

## 3. `dsh/session-catalog.ts`

- `readService(ctx,'sessionPersistence')`：`list()` 拿持久化会话头（id/cwd/createdAt/agentPreset）。
- `readService(ctx,'sessions')`：`list()` 拿活会话（`Session.header`），用于 `live` 与标题。
- `readService(ctx,'sessionTitle')`：`get(session)` 返回 `{title}`，只对活会话取标题；取不到为 null。
- `readService(ctx,'workspaceRegistry')`：`archivedSessionIds`（getter）→ `archived`。
- 合并按 id；排序：未归档在前，同组 createdAt 降序；上限 200；保留 archived（UI 要显示灰色）。
- 任一服务缺失 → `available:false` 与原因；持久化缺失但活会话可用时可只用活会话并注明。
- 在 `dsh/plugin.ts` provide `SERVICES.sessionCatalog`，dispose 收进现有清理链。
- 测试：`tests/dsh/session-catalog.test.ts`（假 ctx：持久化/活会话/归档/标题；不可用）。

## 4. 视觉：多级卡片与控件锁定（见 `DESIGN.md`）

- **三级表面**：页面 `--dsw-alias-bg-layer-1`；区段/面板 `layer-2` + `--dsw-elevation-panel`；
  组内卡片 `layer-3`（或 `layer-2` 内嵌 `layer-3`），**不再“同底色 + 边框”**。
  边框只用于真正的分隔（0.5px `--dsw-alias-border-l2`），不用于卡片外框。
- **禁止蓝色边框**：选中态用填充 token（`--dsw-specific-sidebar-nav-item-active` /
  `--dsw-alias-button-ghost-active-fill`），焦点环只允许在 `:focus-visible`，
  使用 `--dsw-focus-ring-color`（primitive 自带）；输入/按钮不再自定义 outline/边框颜色。
- **控件样式矩阵**（写进 DESIGN.md，逐控件最终样式）：nav cell、row、Button（各 variant）、
  Input、Pill、Tag、SegmentedControl、StateDot、Modal、DisclosureRow、Toast。
- **对齐**：卡片用 grid（概览 2×2 / 窄 1 列；项目 2 列 / 窄 1 列），不使用 flex-wrap 造成
  “3+1” 孤行；所有网格 `minmax(0,1fr)` + `align-items:stretch`；工具栏 `flex-wrap` 且
  `row-gap/column-gap` 一致、末尾按钮不悬空（右对齐或独立行）。
- **排版比例尺**（px）：12/18、13/20、14/22、16/24、20/28；字重 400/500/600；
  间距 4/8/12/16/24；卡片 padding 16；区段间距 24；行间距 8。
- **文本选择**：导航、按钮、标签、页头、卡片标题/标签、元信息行 `user-select:none`；
  记忆正文、id、路径、画像文本、审计条目、输入框 `user-select:text`。
- **动效**：页面切换 180ms 淡入+4px；详情 220ms；刷新按钮 loading 时旋转（reduced-motion 关闭）；
  hover/按下 100–120ms；所有 `transition` 不用 `all`；`prefers-reduced-motion` 去运动留状态。

## 5. 文案规则

- 页头：标题 + ≤1 句短语（≤20 汉字），不写实现/使用说明。
- 开发者信息（扫描上限、API、只读、端点、二级导航）不进入主视线：折叠到“说明”或 tooltip，
  或直接删掉；保留事实但用用户语言（“统计最近 500 条”）。
- 例：页头副标题“记忆、候选、会话隐私与运行读数”；状态区“记忆库就绪”。
- 空态给一句可执行的建议；错误给“发生了什么 + 可以怎么做”。

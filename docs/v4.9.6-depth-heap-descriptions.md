# OMB v4.9.6 — 六个用户命令的简介统一收口

> v4.9.5 只收了四个记忆命令的简介，漏了 `/omb-depth` 与 `/omb-heap`（同样是用户命令，
> 同样带括号与实现细节）。本版补齐并给出六个命令的最终文案（x3 修复位）。

## 1. 最终简介（只改注册 `description`，命令名与用法不动）

| 命令 | 简介 |
| --- | --- |
| `/omb-confirm` | 确认候选记忆，可撤销 |
| `/omb-feedback` | 标记记忆是否有用、过时或不对 |
| `/omb-privacy` | 设置当前对话的记忆隐私模式 |
| `/omb-privacy-clean` | 清理对话的隐私限制记录 |
| `/omb-depth` | 设置本会话的思考深度 |
| `/omb-heap` | 查看进程内存，可抓堆快照排查 |

统一原则：一行说清"这条命令对你做什么"；参数枚举放在 `input.hint`，设计解释与
副作用（暂停事件循环、影响 reasoningEffort）放在命令执行后的回执/文档里，不塞进简介。

# OMB v4.20.0 — 大肥鱼增强设置台（交付记录）

> 本版把标题从“OMB 设置”改为“**大肥鱼增强**”，并按用户 11 点重构设置台：
> 去阴影/去刷新/去跳转、状态机总页、项目工作区折叠、记忆无限滚动与单字检索、
> 响应式动效与弹性对齐、删除全部用户命令并把能力并入前端。

版本 **4.20.0（x2）**：新界面/交互功能更新，不升 x1。构建 **g138**。

## 1. 视觉：2D 卡片，无高光（第 1 点）

- 所有卡片不再使用 `box-shadow`；二级/三级卡改为
  `background: --dsw-alias-settings-card-fill` + `0.5px solid --dsw-alias-settings-card-stroke`
  （导航/内容卡仍为二级卡，内部卡片为三级卡）；
- 记忆/项目列表条目改为**圆角卡片行**（`--dsw-radius-md` + 细边框 + 4px 间距），
  不再用“通栏 + 下划线”；
- 所有颜色/圆角/边框仍走 DSH token，无十六进制色值。

## 2. 概览（第 2 点）

- 删除“去记忆”“去项目”按钮；
- “运行状态”不再折叠：版本/隐私闸门/事件控制器/主动提示四张卡直接并入概览网格，
  与记忆库计数一起构成同屏 8 张三级卡；记忆分布、最近活动继续在下方；
- 右上角“记忆库就绪”状态与页头刷新按钮全部移除；
- 页面数据改为**事件/可见性驱动**：`useLoad` 每 8 秒且在窗口重新聚焦时自动重读，
  用户不需要手动刷新。

## 3. 响应式平滑（第 3 点）

- 二级侧边栏宽度/内边距、页面内边距/间距、内容区内边距都加 180ms 过渡；
- 导航文字用 opacity 过渡而不是 `display:none` 跳变；图标固定左对齐，窗口跨断点时不抖动；
- 卡片网格改为 2/4 列（≥760 四列），容器查询 600/820/520 分别控制侧边栏、
  宽屏列表+详情、窄屏单列。

## 4. 记忆：无限滚动 + 单字检索（第 7 点）

- 去掉“第 N 页 · 本页 M 条 / 上一页 / 下一页”；
- 初始 30 条，列表滚动接近底部时自动请求下一批 30 条并追加；
- 后端单字回退：`searchFuzzy` 最小长度 2 → 1（仍只读、有界、遵守状态/类型/标签过滤）；
  连续中文正文里的单字现在能检索到。

## 5. 状态机总页（第 6 点）

- 新增第五个导航页“**状态机**”：`GET /omb/api/machines` 聚合全部 OMB 会话的
  控制器状态，按项目根/工作区分组；显示每个会话的 phase、任务约束、候选；
- sealed 与归档会话仍在列表但**不读状态**；控制器未接线或会话目录不可用时如实降级；
- 项目子页仍保留单会话的“状态机”区（任务/候选手动增删清空），作为跨会话总览的入口；
- 手动编辑仍只在项目页（需要会话上下文与隐私档位）。

## 6. 项目页：默认折叠的工作区树（第 10 点）

- 项目页不再自动选中第一个会话；工作区卡片默认收起；
- 点击工作区展开到会话级；会话按 `parentId` 跟随母会话缩进（子会话标签“子会话”）；
- 归档会话/工作区灰显且不可读；选中会话后右侧显示深度/隐私/状态机/画像/隐私维护；
- 推理深度改为 SegmentedControl（快速/标准/深入），调用 `POST /omb/api/depth`；
  不再依赖 `/omb-depth`。

## 7. 删除用户命令，能力并入前端（第 11 点）

- 移除 `/omb-depth`、`/omb-heap`、`/omb-confirm`、`/omb-feedback`、
  `/omb-privacy`、`/omb-privacy-clean` 的注册；实现模块保留，由 UI 端点复用：
  - 深度 → 项目页 SegmentedControl + `POST /depth`；
  - 确认/过时/恢复 → 记忆详情动作；
  - 反馈（有用/错误/过时/噪声）→ 记忆详情“反馈”行 + `POST /feedback`；
  - 隐私设置/维护 → 项目页；
  - 堆快照：无 UI 入口（不影响内存读数与 `omb_status` 工具）。
- `tests/dsh/no-user-commands.test.ts` 断言启动不再注册任何 OMB 用户命令。

## 8. 其他

- 第 8 点：筛选/调整全部使用 SegmentedControl 与 Pill，没有滑块；
- 第 9 点：工具栏/卡片使用 `minmax(0,1fr)`、`flex:1 1 auto`、固定控件不拉伸、
  行内 `min-width:0`；卡片网格按容器断点 2/4 列对齐，避免竖直长条与右端大空档；
- 标题与侧边栏标签：**大肥鱼增强**。

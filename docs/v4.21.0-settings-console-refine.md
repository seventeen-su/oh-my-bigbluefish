# OMB v4.21.0 — 大肥鱼增强设置台精修（交付记录）

> 用户本轮 7 点：拼接侧边栏与主卡、去掉概览默认空白、标准下拉框、状态机真正接线、
> 母子会话名称/折叠/溢出/动效/旧版兼容、运行中会话设置锁定。

版本 **4.21.0（x2）**，构建 **g139**。视觉规范仍以 `DESIGN.md` 为准。

## 1. 侧边栏与主卡拼接（第 7 点）

`.omb-body` 现在是**一张二级卡**：`layer-2` 填充 + `0.5px` 外框 + 16 圆角、`overflow:hidden`；
导航与内容之间用**与外框同色**的 `0.5px` 竖线分隔（`--dsw-alias-border-l2`），
不再是两张分离卡片。导航宽度/内边距、内容内边距仍做 180ms 过渡。

## 2. 默认不激活、无概览（第 1 点）

- 导航只剩：**记忆、项目、状态机、个人画像**；概览页与运行状态卡全部删除；
- 初始 `page = null`：右侧主卡为**空白**，导航没有选中项；点击侧边栏才进入子页；
- 数据在所有页面按 8 秒/窗口聚焦自动重读，不需要刷新按钮。

## 3. 标准选项框 + 下拉列表（第 3 点）

记忆库筛选（库/状态/类型）、新建记忆（库/类型）、项目设置（推理深度/隐私模式）、
个人画像（轴）全部改为原生 `<select>`（`.omb-select`），不再使用 SegmentedControl/Pill；
没有滑块/range 控件。

## 4. 状态机真正接线（第 4 点）

根因：`modules/memory/index.ts` 虽然 `provide(SERVICES.memoryControllerAdmin)`，
但 `createUiService` 的 deps 漏传 `controllerAdmin`，导致 UI 永远报“未接线”。
v4.21.0 显式注入：

```ts
controllerAdmin: kernel.service<ControllerAdminPort>(SERVICES.memoryControllerAdmin)
```

并有 bundle 契约测试钉住；项目页单会话状态机与“状态机”总页都恢复可用。

## 5. 母子会话（第 5 点）

- **不再错误标注子会话**：只有实际挂在同工作区母会话下（`depth > 0`）才显示“子会话”；
  找不到母会话的旧会话按根会话处理；
- **名称**：有标题用标题；旧日志没有标题时用“会话 <短 id>”，不再用 cwd 冒充同名，
  母/子名称可区分；`parentId` 仍由目录透传；
- **溢出**：子会话缩进改用 `padding-left`，不再用 `margin-left + width:100%` 撑破右侧；
- **默认收起 + 动效**：工作区、母会话都默认收起；展开/收起用 CSS Grid
  `grid-template-rows 0fr ↔ 1fr` 200ms 过渡；箭头 `▾/▴` 替代“展开/收起”文字
  （`aria-label` 仍可读）；
- **旧版兼容**：`agentPreset` 缺失的旧 OMB 会话不再被整条过滤（显示“旧会话”标签），
  同时保留归档、隐私、深度等缺失字段的安全降级。

## 6. 运行中会话设置锁定（第 6 点）

`selected.active` 时推理深度/隐私模式下拉框禁用（灰色），并显示
“会话运行中：设置已锁定，结束后可修改”；状态机/画像/隐私维护保持只读或规则不变。

## 1. 会话状态机读数（运行状态页）

`UiRuntime.situation`（v4.15.4）：当前活跃会话的
`state / tier / turn / idleMs / lastTurnEndReason / interrupted / unresolved /
goals / todos / workspace{root,switches,previousRoot,since}`。

- 来源：`SERVICES.activeSession.current()` + `SERVICES.sessionState.situation(sessionId)`；
- 只取展示所需字段（不把整份 situation 塞给页面）；服务不可用/无会话时页面写"未接线/未知"；
- 页面新增"会话状态机"一节：会话、状态、回合、空闲、上回合结局、目标/待办、工作区切换次数与上一处。

## 2. bundle 发布契约测试

`tests/dsh/ui-bundle.test.ts` 钉住：

- `packages/memory/package.json` 的 `dsh.client.platform === 'web'`、`immediately === true`、
  `inject` 是数组、`exports['./client'] === './client.js'`，且文件真的存在；
- `client.js` 使用 `window.__ModuleLoader__.load`、id 等于包名 `@omb/memory`，
  注册 `main` 与 `sidebar.panellist` 两个入口；
- 写动作只打 `/omb/api` 的 `confirm`/`resolve`（没有别的写端点）。

任何一项漂移都会让宿主启动 loud fail 或页面静默无入口，因此用测试而不是"记得检查"。

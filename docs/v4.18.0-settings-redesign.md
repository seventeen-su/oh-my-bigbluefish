## 2. 手动记忆操作（用户第 1 点）

浏览器 → `POST /omb/api/memory`：

- `create`：库（用户/项目）× 类型 × 内容 × 标签；写入 `assertedBy='user'`、
  `sourceRef='ui:manual'`、内容哈希、写后查回；项目库需要当前会话。
- `update`：内容/类型/标签；保留 id/时间/来源/确认者/使用计数；文本变则重算哈希；只允许活跃记录。
- `delete`：硬删除并清理边/向量（store `forget`），查回确认不存在。
- `mark`：`confirm`（与 `/omb-confirm` 同一实现）、`obsolete`（写 validTo）、
  `revive`（只在未被取代时清 validTo）。
- 所有写入经库访问边界（隐私闸门）；拒绝文本原样呈现；文本 1..4000、标签 ≤8×≤24。

## 3. 项目页：会话目录、归档、深度、隐私、画像（用户第 3 点）

新增内核服务 `SERVICES.sessionCatalog`（`dsh/session-catalog.ts`）：

- 读宿主 `sessionPersistence.list()`（持久化会话头）、`sessions.list()`（活会话）、
  `sessionTitle.get()`（活会话标题）、`workspaceRegistry.archivedSessionIds`（归档集合）；
- 合并/去重/排序（未归档优先 + createdAt 降序）、上限 200；任一读取失败绝不抛，
  缺一路时 `available:true` 且 reason 写明“仅活会话/仅持久化会话”，两路全缺才不可用；
- 本进程内新建但尚未落盘的活会话也会进目录。

`GET /omb/api/sessions` 由 `ui.sessions()` 组装：

- 只保留 `agentPreset === 'omb'`；
- `root` = `SERVICES.projectRoot.resolve(cwd)`，`active` 来自 sessionRuntime，
  `depth` = `kernel.focus(id)`，`privacy` = `PrivacyAdminPort.modeOf(id)`；
- **归档会话**：列表保留但置灰、不可点击、不可读；`profile` 请求返回
  `available:false,reason:'已归档会话不可读'`，隐私设置也不可操作。

`GET /omb/api/profile?sessionId=` 按会话 cwd → git 根 → 项目画像；缺 cwd/归档/非 git
都如实说明。推理深度只读展示（修改仍走 `/omb-depth`）。

## 4. 个人画像（用户第 4 点）

`GET /omb/api/personal` 读 `SERVICES.profile`：`status()`、`entries(sessionId)`、
`conflicts(sessionId)`、`renderDeclared(12,sessionId)`；页面按轴（稳定偏好/能力/意图/
协作方式）分组，标注已声明/推断、依据、时间；冲突并列显示，不替用户裁决；
能力轴明确“仅本会话/关闭”。

## 5. 视觉：多级卡片与控件锁定（用户第 5/6/12/13 点）

- **二级卡**：导航轨与内容卡都是 `bg-layer-2` + `--dsw-elevation-panel`
  （亮色主题 `bg-layer-1/2/3` 可能同色，所以**不能只靠底色差**，也不能只留一个边框）；
- **三级卡**：详情、组内卡片、空态、通知 = `bg-layer-3` + `--dsw-elevation-soft`；
- 卡片**不再用边框**表达层级；0.5px 发丝线只用于区段/行分隔；
- 控件锁定（详见 `DESIGN.md` §5）：选中一律用填充 token，不用蓝色描边；
  焦点环只在 `:focus-visible`；primitive 的边框/圆角/颜色不覆盖；
- 排版：20/15/13/14/12、行高 28/22/20/22/18，字重 400/500/600；
  间距 4/8/12/16/24；卡片 padding 16；
- 对齐：概览 4 卡在宽容器 2×2、窄容器 1 列；网格 `minmax(0,1fr)` + `stretch`，
  不再出现 flex-wrap 的“3+1”孤行；
- 子页内部滚动条隐藏（`scrollbar-width:none` + `::-webkit-scrollbar`），滚动能力保留。

## 6. 动效与文本（用户第 9/10/11/14/15 点）

- **方向感**：子页切换按导航顺序从右/左侧浮入（`translateX(±14px)` + opacity +
  scale .995，220ms `cubic-bezier(.22,.61,.36,1)`），不是单纯淡入；
- 详情栏 220ms `flex-basis`/滑入；刷新图标 900ms 旋转；hover 120ms；
- `prefers-reduced-motion` 取消位移/旋转/宽度过渡；
- 文本选择：界面骨架（导航/按钮/标签/页头/元信息）不可选；记忆正文、id、路径、
  画像、审计、输入框可选；
- 文案：页头只留标题 + 一句短语；运行/技术细节折叠进“运行状态”/“说明”；
  去掉“页面只读”“二级侧边栏”“扫描上限”等开发者叙述；状态只给结论。

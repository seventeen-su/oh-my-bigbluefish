# OMB v4.15.2 — 侧边栏运行状态与项目画像页

> 4.15.0 同功能收尾（x3）：侧边栏从"记忆库/候选"扩展到**运行状态**与**项目画像**两个只读页签，
> 对应指令第 3 项里的"状态机/画像"手动查看。

## 1. 页签

- **运行状态**：OMB 版本、记忆库就绪/项目库数、隐私闸门（可写/禁写 + 原因）、
  事件控制器读数（模式/事件/persist/写入/查回失败/幂等跳过）、捕获与主动性读数
  （偏好写入/失败/主动提示命中/跟进）、活动日志（累计计数 + 最近 8 条，不含正文）；
- **项目画像**：项目根、cwd 相对根、分支/HEAD、顶层目录、文件索引（行/符号/导入）、
  画像摘要（≤1500 字符，只读）。没有会话 cwd / 画像服务未接线时**如实写原因**，不猜路径。

## 2. 数据来源（不新增订阅）

- `UiService.runtime()`：内存核在装配时注入闭包，读取已有台账——
  `StoresService.status()`、`SERVICES.privacy`（`decideUnattributed`）、
  `activityRef.summary()`、`capture.stats()`；版本取 `OMB_VERSION`；
- `UiService.profile()`：经 `SERVICES.projectProfile.read(cwd)`；cwd 来自
  `SERVICES.activeSession.cwd()`（宿主告知的唯一来源），缺失就返回 `available:false` + 原因；
- 路由新增 `GET /omb/api/runtime`、`GET /omb/api/profile`（同样只读、同源、no-store）。

## 3. 边界

- 两个页签都是**只读快照**：不触发画像重建、不改任何状态；
- 画像摘要与结构只在页面打开时读取（缓存由宿主画像服务负责），不进入模型上下文；
- 活动日志只显示动作类型/详情（不含记忆正文）。

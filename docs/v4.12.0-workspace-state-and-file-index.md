# OMB v4.12.0 — 跨工作区状态机与文件索引

> 用户指令第 6 项（x2 新功能）：补全**跨工作区状态机**，并深化项目认知（**文件索引**）。

## 1. 跨工作区状态机（`dsh/state-machine.ts`）

之前 `situation()` 只有 `cwd`，没有"本会话换过项目"这个事实。v4.12.0 增加：

- 选项 `rootOf(cwd)`：cwd → 项目根（生产注入 `dsh/project-root.ts` 的 git root 解析）；
- 每会话记录：`workspace: { root, cwd, since, switches, previousRoot }`；
- **惰性观测**：只在读取 `situation()` 时更新，不新增订阅/定时器；
- **按 git root 判定**：同一仓库内换子目录只更新 `cwd`，不算切换；
- 有界：最多跟踪 256 个会话（超出淘汰最旧），不新增无界表；
- `omb_project` L0：切换过时显示 `本会话切换工作区 N 次（自 X；上一处 Y）`。

边界：读数只在本进程内；会话注销/进程重启后从零开始（不是持久审计）。

## 2. 文件索引（`dsh/project-profile.ts`）

之前画像只有目录级源码统计与跨文件依赖边，回答不了"哪些文件是核心"。v4.12.0 增加：

- `ProjectProfileStructure.files`：`{ path, lines, symbols, imports }`；
- 排序：`symbols + imports` 降序、路径升序（确定性），最多 12 个文件；
- 数据来自同一次扫描（`analyzeSource` 的符号/导入/行数），不新增 IO；
- `omb_project` L1 显示前 4 个：`文件索引 src/app.ts(1符号/1导入)、…`；
- 仍受画像的扫描上限与 2400 字符快照预算约束。

边界：这是"规模索引"，不是完整 repo-map/类型图；符号数是导出声明数、导入数是说明符数。

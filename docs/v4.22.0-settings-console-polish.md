# OMB v4.22.0 — 大肥鱼增强设置台打磨（交付记录）

> 本轮 13 点：极窄溢出、侧栏尺寸、历史标题、子会话宽度/去重路径、选择器箭头、
> 状态机总页检索与管理、列表遮罩动效、#232324 表面、仿桌面通知控件、弹窗排版、
> omb-meta 一致性、操作 Toast。

版本 **4.22.0（x2）**，构建 **g140**。

## 1. 极窄宽度与侧栏（第 1/2 点）

- 页面/主卡/内容/行/卡片全部 `min-width:0`、`max-width:100%`、`overflow-wrap:anywhere`；
  `.omb-page` 与 `.omb-content` 裁掉横向溢出；新增 ≤380px 紧凑断点；
- ≤617px 侧栏宽度从 48 → **56px**，padding 从 4 → **6px**，导航单元格 padding 8px，
  图标居中，不再挤成一条。

## 2. 历史会话真实标题（第 3 点）

- `SessionCatalogPort.title(id)`：活会话先走 `sessionTitle`，历史会话通过
  `sessionPersistence.open(id,'read')` 读日志，取最后一个 `session/title` 事件；
  `Map` 缓存 ≤200（含 null）、1.5s 超时、句柄必 close、异常一律 null；
- `GET /omb/api/session-title?id=`；项目页展开工作区后按需补读标题，
  状态机总页也接入 `useSessionTitles`；取不到才回退“会话 短id”，不再用 cwd 冒充。

## 3. 母子会话（第 4/5 点）

- 子会话宽度按缩进**削减**（`width: calc(100% - indent)` + `margin-left`），
  右侧与父级对齐，不再溢出；
- 会话行不再重复显示 cwd（工作区只在 workspace 标题显示一次），降低行高；
- 母会话默认收起；箭头用 DSH `IconChevronUp/Down`，右侧垂直居中，
  工作区与母会话共用同一图标语言（对应 picker 小三角）。

## 4. 状态机总页（第 7 点）

- 卡片之间加 8px 间距（`.omb-stack`），任务/候选真实内容可见；
- 新增搜索（会话/任务/候选）与阶段筛选 Select；
- 卡片内可添加任务、移除任务/候选、清空任务/候选（写 `POST /controller`），
  归档/封存会话锁定；操作结果走 Toast。

## 5. 列表遮罩/动效（第 8 点）

- 窄容器（≤819px）详情打开时 `.omb-list-pane` 透明度归零并禁用指针，
  关闭后 180ms 过渡恢复，圆角缝隙不再透出列表。

## 6. 表面与控件（第 9/10/12 点）

- 二级大卡背景按用户指定 `#232324`（唯一允许的十六进制表面色）；
- 选择框/文本域仿 `dsh-desktop-notify` 的 CONTROL：32px、无边框、
  `bg-module-platform`、8px 圆角、聚焦不画环；选择器小三角用 `::after` 居中对齐；
- `omb-meta` 与 `omb-row-meta` 统一 4×8 间距、12/18 字级、tertiary 色。

## 7. 弹窗与 Toast（第 11/13 点）

- 记忆表单、个人画像表单内容包在 `.omb-form`（gap 12），弹窗内不再挤成一团；
- 记忆/状态机/项目/个人画像的新增、编辑、删除、反馈、隐私、深度等写操作
  统一用 `Toast`（成功带 success 图标，失败显示原因），不再在页面里堆
  “已删除该槽位的显式条目…”“已写入个人画像”等内联提示。
